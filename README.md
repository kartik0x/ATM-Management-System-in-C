# 🏧 ATM Management System in C

A console-based ATM Management System developed in C.

## Features

- Secure 4-digit PIN Login
- Maximum 3 Login Attempts
- Balance Inquiry
- Deposit Money
- Withdraw Money
- Input Validation
- Exit Option

---

## Technologies

- C Programming
- GCC Compiler
- VS Code
